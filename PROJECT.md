# Muhasba: Reflect. Improve. Together.

A shared habit and goal tracker for friends. Users track daily activities
and can see their friends' activity.

## Stack
- Next.js (App Router), TypeScript, Tailwind CSS
- Supabase (Auth with Google + email, Postgres, Row Level Security)
- Deployed on Vercel

## Rules
- Small components, one feature per branch
- Never hardcode secrets; use .env.local
- Every table must have Row Level Security enabled
- Only change what is asked; do not refactor unrelated files
- Explain briefly what each new file does

## Roadmap
1. Skeleton + deploy
2. Auth (Google + email)
3. Dashboard with category cards
4. Namaz tracker (5 daily prayers, weekly/monthly report)
5. Friends + friend activity view
6. Privacy testing
(Later: fitness, learning, money, time)
